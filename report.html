Лабораторная работа № 4

Калькулятор скидок

Выполнил(а) _________________________ · Группа __________

Цель

Разработать калькулятор стоимости нескольких товаров с категорийными скидками и учебной ставкой НДС 22%.

Ход работы

Для каждой позиции хранятся цена, категория и параметры ручной скидки. Скидки категорий составляют 5% для электроники, 15% для одежды, 10% для продуктов, 20% для книг и 0% для прочих товаров. Ручная ставка от 0 до 50% заменяет категорийную.

Промокод WELCOME10 вычитает ещё 10% из суммы после первой скидки. При включённом НДС 22% начисляются на остаток. Расчёт ведётся в копейках с округлением на каждом денежном шаге. В истории остаётся до пяти итогов.

Результат проверки

Для книги за 1 000 ₽, промокода WELCOME10 и включённого НДС браузер показал 878,40 ₽. После двух скидок остаётся 720,00 ₽, из них рассчитывается НДС 158,40 ₽.

Воспроизведение

Распакуйте архив, выполните npm.cmd ci и npm.cmd run dev из папки с package.json. Откройте адрес, указанный Vite в терминале. Добавьте вторую позицию и сравните сумму по строкам с общим итогом. После изменения входных данных нажмите «Рассчитать» снова.
